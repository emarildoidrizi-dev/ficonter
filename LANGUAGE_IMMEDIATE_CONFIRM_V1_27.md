# FICONTER V1.27 — Immediate language confirmation

Language selection is the deliberate exception to FICONTER's explicit-save governance rule.

- Selecting a language applies it immediately.
- The picker closes immediately.
- No separate Save language button is shown.
- The selected language is persisted to the signed-in account as part of the same action.
- If account persistence fails, the UI and browser preference roll back to the previously confirmed language.
- All other editable settings retain their existing Save / Apply / Confirm requirements.
