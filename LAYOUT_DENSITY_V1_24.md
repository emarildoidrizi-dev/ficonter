# FICONTER V1.24 — Strong Layout Density

## Goal
Make Comfortable and Compact feel like genuinely different platform layouts instead of minor spacing variants.

## Comfortable
- Larger page margins
- Larger card/panel padding
- Larger touch controls
- Taller table rows
- Wider section/grid gaps
- More generous Settings navigation and panel spacing

## Compact
- Substantially tighter page margins
- Smaller card/panel padding
- Shorter desktop controls while preserving mobile touch usability
- Denser tables
- Tighter grids and action bars
- Smaller Settings navigation footprint

## Responsive behavior
Phone/tablet density remains safe for touch. Compact reduces whitespace and card gaps without shrinking mobile controls below a practical touch target.

## Save governance
Selecting a density remains draft-only. It is committed only by **Save appearance**. Leaving without Save restores the last saved density.
