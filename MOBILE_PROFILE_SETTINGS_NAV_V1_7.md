# FICONTER Mobile Navigation V1.7 — Settings in Profile Menu

## Locked navigation rule

Settings is no longer shown in the mobile **More** navigation sheet.

The avatar/profile menu is now the account control location across Personal, Business, and Admin:

1. Profile
2. Settings
3. Log out

The **More** menu is reserved for app modules, tools, and authorized Admin sections only.

## Scope
- Personal mobile header account menu
- Business mobile header account menu
- Admin mobile experience through the Personal/Admin shell
- FiconterNativeAppChrome account sheet fallback
- More drawer route groups

## Preserved behavior
- Logo remains branding only.
- More remains the only full module navigation command.
- Admin routes remain permission-gated.
- Active business switching remains separate.
- Contextual Back navigation remains unchanged.
- Desktop navigation remains intact.
