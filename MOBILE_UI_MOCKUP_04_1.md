# FICONTER Mobile UI — Mockup 04.1

This refinement follows the approved mobile header/navigation request.

## Changes
- FICONTER emblem is now a static brand mark, not the navigation trigger.
- A dedicated hamburger/menu icon sits directly under the current page title (Overview on Home).
- Personal bottom navigation now shows Settings in the far-right position instead of More.
- The Settings route is removed from the menu sheet so Settings appears only in the bottom dock.
- The menu sheet remains accessible through the header menu icon.
- Business bottom navigation keeps More because Business has no matching personal Settings route.
- Mobile page top clearance was increased to account for the taller two-level header.

No financial calculations, Supabase contracts, subscription rules, or desktop layouts were changed.
