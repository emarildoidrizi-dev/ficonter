# FICONTER Mobile Mockup 04.13 — Overview refinement

The mobile Overview now follows the approved editorial reference as a strict vertical hierarchy rather than allowing earlier mobile layout phases to compete with the final design.

## Changes

- Keeps the mobile order: hero → Add money → Available now → Financial health → remaining overview intelligence cards.
- Makes the Available now header an explicit navigation affordance with a wallet icon and chevron.
- Keeps Still to pay and Left after everything as large one-column touch rows.
- Uses Georgia / Times as the formal display type family from the approved visual reference, while small utility labels retain a highly legible system sans-serif.
- Replaces fixed light-only overview colours with FICONTER semantic theme tokens (`--text-*`, `--surface-*`, `--solid-*`, `--gold`, `--sage`).
- Uses the currently active time-aware wallpaper (`--living-scene`) behind the hero instead of permanently forcing the morning photograph.
- Removes final-shell geometry conflicts that could make the mobile cards appear side-by-side, compressed, or visually disconnected.
- Adds strong visible focus states and 50–82 px touch targets for key controls.

Desktop Overview behavior and financial calculations are unchanged.
