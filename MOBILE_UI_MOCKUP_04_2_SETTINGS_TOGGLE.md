# FICONTER Mobile Mockup 04.2 — Settings toggle

The Personal mobile dock Settings control now behaves as a toggle:

- First tap from any non-Settings screen opens `/dashboard/settings` and activates the Settings dock state.
- Second tap while Settings is active closes Settings by returning to `/dashboard` (Overview) and deactivates the Settings dock state.
- Business dock behavior remains unchanged.
- Existing Settings page logic, data, and module behavior are unchanged.
