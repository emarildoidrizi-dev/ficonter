# FICONTER Mobile Mockup 04.7 — Remove duplicate Settings index card

## Change
- Removed the old in-page Settings index card on phone/tablet layouts.
- The bottom Settings control and its instant sheet are now the only Settings section picker on mobile.
- Direct section routes such as `/dashboard/settings?section=security` continue to render the selected Settings detail screen.
- Desktop Settings keeps its existing navigation workspace.
- Profile remains separate from Settings.

## Interaction
1. Tap **Settings** in the bottom dock.
2. The instant Settings sheet opens immediately.
3. Choose a section.
4. Only that section detail view appears; the duplicate account/settings index card no longer appears underneath.
