# FICONTER V1.31 — Profile routes to Account preferences

- The standalone Profile presentation is retired.
- `/dashboard/profile` remains only as a permanent compatibility redirect to `/dashboard/settings?section=profile`.
- Every Profile action in Personal, Business, mobile account sheet, and More opens Profile inside Account preferences directly.
- Profile photo, name, display name, and login email remain managed in Settings > Profile.
- Email-change confirmation returns to the same Settings > Profile section.
- PWA cache generation is bumped so installed clients receive the routing change.
