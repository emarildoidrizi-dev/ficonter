# FICONTER V1.32 — Surface Opacity

- Adds a Surface opacity control under Settings → Appearance.
- Range: 55%–100% in 5% steps.
- Default: 100%, preserving the current UI until the user changes it.
- The slider is draft-only: it previews inside Settings and does not alter the live platform until **Save appearance** succeeds.
- Saved opacity applies globally to semantic surfaces used by Personal, Business, Admin, desktop, tablet and mobile.
- Only surface backgrounds become translucent. Text, numbers, icons, logos and controls remain fully opaque.
- Existing V1.29 theme contrast protection continues to audit foreground readability over translucent surfaces.
- The setting persists in authenticated metadata and local storage and is included in account PDF exports.
