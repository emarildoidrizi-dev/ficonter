# FICONTER V1.32 upload instructions

1. Use the current repository containing V1.31.
2. Extract this ZIP directly into the repository root, alongside `app`, `components`, `lib`, `public`, `scripts` and `package.json`.
3. Replace the included files when prompted.
4. Do not delete any other files.
5. In GitHub Desktop, review the changes and commit with:
   `feat(appearance): add saved global surface opacity control`
6. Push origin and wait for GitHub Actions and Vercel.
7. After deployment, close/reopen FICONTER or hard-refresh once so the new PWA cache generation is active.
