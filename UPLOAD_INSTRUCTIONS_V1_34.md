# Upload instructions — FICONTER V1.34

1. Extract this ZIP directly into the current FICONTER repository root.
2. Replace the included files when prompted.
3. Do not delete any other files.
4. Commit with: `feat(theme): preview theme and typography instantly without refresh`
5. Push and wait for GitHub/Vercel.
6. After Vercel is Ready, reopen FICONTER (installed PWA users should fully close and reopen once).

Expected behaviour: clicking a theme changes the visible palette and typography immediately. Save appearance persists the choice; leaving without saving restores the last saved appearance.
