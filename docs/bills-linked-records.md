# Bills linked records

The Bills workspace exposes the real Transaction records generated by each Bill.

Relationship sources:

- `bills.transaction_id` for direct Bill payments.
- `automatic_payment_runs.source_id` + `transaction_id` for recurring automatic Bill runs.

Only transactions present in the encrypted Transaction provider are rendered. No relationship is inferred from descriptions or categories.

Each linked record routes to `/dashboard/transactions/[id]` for the complete Transaction Details view.
